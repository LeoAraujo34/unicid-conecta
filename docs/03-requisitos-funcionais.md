# 3. Requisitos funcionais

Todos os requisitos seguem a forma "O sistema deverá ...".

## 3.1 Autenticação (RF-AUT)

| ID | Requisito |
|---|---|
| RF-AUT-001 | Permitir a autenticação do usuário. |
| RF-AUT-002 | Identificar o perfil do usuário autenticado. |
| RF-AUT-003 | Direcionar o usuário para a interface correspondente ao seu perfil. |
| RF-AUT-004 | Permitir que o usuário encerre sua sessão. |

## 3.2 Aluno (RF-ALU)

| ID | Requisito |
|---|---|
| RF-ALU-001 | Apresentar ao aluno uma página inicial com acesso às funcionalidades disponíveis. |
| RF-ALU-002 | Permitir ao aluno acessar a área de chamados. |
| RF-ALU-003 | Permitir ao aluno acessar sua carteirinha digital. |

## 3.3 Chamados (RF-CHA)

| ID | Requisito |
|---|---|
| RF-CHA-001 | Permitir que o aluno ou professor registre um novo chamado. |
| RF-CHA-002 | Disponibilizar as categorias de ocorrências cadastradas. |
| RF-CHA-003 | Disponibilizar as localizações cadastradas da instituição. |
| RF-CHA-004 | Permitir que o aluno ou professor informe a descrição da ocorrência. |
| RF-CHA-005 | Permitir anexar uma imagem à ocorrência. |
| RF-CHA-006 | Validar os campos obrigatórios antes do registro do chamado. |
| RF-CHA-007 | Gerar um protocolo único após o registro do chamado. |
| RF-CHA-008 | Apresentar uma confirmação após o registro do chamado. |
| RF-CHA-009 | Permitir ao aluno consultar seus chamados registrados. |
| RF-CHA-010 | Apresentar o status atual de cada chamado. |
| RF-CHA-011 | Permitir a consulta dos detalhes de um chamado. |
| RF-CHA-012 | Apresentar o histórico de alterações de status. |
| RF-CHA-013 | Apresentar as atualizações publicadas pela equipe responsável. |
| RF-CHA-014 | Apresentar data e horário das atualizações do chamado. |
| RF-CHA-015 | Permitir filtrar chamados por status. |

## 3.4 Operacional (RF-OPE)

| ID | Requisito |
|---|---|
| RF-OPE-001 | Apresentar um painel inicial para usuários da operação/manutenção. |
| RF-OPE-002 | Exibir a quantidade de chamados conforme sua situação. |
| RF-OPE-003 | Apresentar a fila de chamados registrados. |
| RF-OPE-004 | Permitir consultar os detalhes de um chamado. |
| RF-OPE-005 | Apresentar solicitante, categoria, localização e prioridade do chamado. |
| RF-OPE-006 | Permitir pesquisar um chamado pelo protocolo. |
| RF-OPE-007 | Permitir filtrar chamados por status. |
| RF-OPE-008 | Permitir filtrar chamados por prioridade. |
| RF-OPE-009 | Permitir que usuários autorizados alterem o status do chamado. |
| RF-OPE-010 | Permitir registrar uma atualização sobre o atendimento. |
| RF-OPE-011 | Registrar o usuário responsável por uma alteração de status. |
| RF-OPE-012 | Registrar data e horário das alterações realizadas. |
| RF-OPE-013 | Permitir que um chamado seja marcado como resolvido (**essencial**). |
| RF-OPE-014 | Separar chamados ativos dos chamados resolvidos. |
| RF-OPE-015 | Permitir atribuir um responsável ao chamado. |
