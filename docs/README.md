## Convenção dos identificadores

`<TIPO>-<ÁREA>-<NÚMERO>`

- **RF** = Requisito Funcional · **RNF** = Requisito Não Funcional
- Áreas: `AUT` autenticação · `ALU` aluno · `CHA` chamados · `OPE` operacional · `SEG` segurança · `USA` usabilidade · `DES` desempenho · `CON` confiabilidade e integridade · `MAN` manutenibilidade
